# 店舗管理アプリ セットアップ

## ファイル構成

| ファイル | 役割 |
|---|---|
| `store-manager.html` | アプリ本体 |
| `sync-server.js` | 店内のPCで動かす同期サーバー（おすすめ） |
| `cloudflare-worker.js` | インターネット経由で同期する場合のサーバー |

---

## 方法1：店内のPCで動かす（おすすめ）

外部サービスの契約もインターネットも不要です。店内Wi-Fiだけで完結します。

### 準備

1. 店に置くPC（Windows / Mac / 中古ノートでも可）に **Node.js** をインストール
   → https://nodejs.org/ の LTS 版
2. `store-manager.html` と `sync-server.js` を **同じフォルダ** に置く

### 起動

そのフォルダでコマンドプロンプト（Macならターミナル）を開いて：

```
node sync-server.js
```

画面にこう表示されます：

```
  タブレットで開く場合（同じWi-Fiに繋いでください）:
    http://192.168.1.20:8787
```

### タブレット側

各タブレットのブラウザでその **URLを開くだけ**。
アプリの「外部同期URL」は自動で設定されるので、設定画面を触る必要はありません。

ホーム画面に追加しておくと、アプリのように起動できます。

### データ

`store-data.json` に自動保存されます。PCを再起動しても残ります。
このファイルをコピーしておけばバックアップになります。

### 注意

- PCの電源が入っていて、`node sync-server.js` が動いている間だけ同期します
- PCとタブレットが同じWi-Fiに繋がっている必要があります
- PCのIPアドレスは再起動で変わることがあります。ルーターの設定で固定するか、
  変わったら新しいURLを開き直してください

## 方法2：Cloudflare Workers（インターネット経由）

店にPCを置きたくない場合や、外出先からも見たい場合。無料枠で足ります。

手順は `cloudflare-worker.js` の冒頭コメントに書いてあります。
デプロイ後、各タブレットの
**設定 → 連携とデータ → 外部同期URL** に `https://xxxx.workers.dev/sync` を入力します。

この場合 `store-manager.html` は各タブレットに配るか、
どこかのサーバー（Netlify、GitHub Pages など）に置いてください。

---

## 同期のしくみと制限

- 各端末は **2〜4秒おき** にサーバーへ問い合わせて、最新の状態を取り込みます
- 状態を変えた端末が、その内容をサーバーへ送ります
- **後から送られたものが優先されます（後勝ち）**

そのため、**まったく同時に別々の端末が同じ卓を操作すると、片方の変更が消える**
可能性があります。卓ごとに担当が分かれていれば実用上は問題ありませんが、
会計処理などは1台に集約する運用をおすすめします。

## 権限とPIN（初期値）

| PIN | 権限 | 見られる画面 |
|---|---|---|
| 1111 | 注文専用 | 注文端末（卓固定） |
| 2222 | ホール | テーブル・注文・初回・伝票・売上 |
| 3333 | 厨房 | 厨房・在庫 |
| 9999 | 管理者 | テーブル・初回・伝票・厨房・売上・設定 |

PINは 設定 → アカウントと権限 で変更できます。運用前に必ず変えてください。
また、ログイン画面に表示されているPIN一覧も、運用時は消してください
（`viewLogin` 関数の `login-hint` の部分）。

## 注文端末の卓番設定

各タブレットの注文画面 右上の歯車 → 管理者PIN → 卓番を選択。
端末ごとに保持されます。
